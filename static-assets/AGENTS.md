# 静态资源智能体执行约定

先读 README.md、WORKFLOW.md 和本次指定 task_id 对应的 tasks.json 条目，再开始处理。项目根 AGENTS.md 仍适用。

## 边界
只处理分配给你的静态图片。不得改 decoded、原生库、smali、打包脚本、游戏速度、剧情、其他任务图片；不得安装 APK、提交远端或发布。originals、mapping.json 是只读基线；禁止对已超分图再次超分。当前不接入 APK 图片加载。

## 开工
未指定任务时，列出候选并请求协调者分配，不自行占用其他人的任务。共享工作区由协调者串行修改 tasks.json 的 owner/status，执行者只写自己的 submissions/<task_id>/<author>/。任务状态依次为 unclaimed、claimed、submitted、accepted 或 needs_revision。submitted 不代表已验收或可打包。

先逐图检查大小、透明通道、切片和所有调色板。文件名用途只是线索。记录 category 和算法选择；无法确认用途、混合类别、未知银行关系或图集无法保持边界时停止该任务并报告，不猜测。背景/人物 4×，其他 2×；像素风优先 xBRZ，插画优先 Real-ESRGAN。人物像素精灵可选 xBRZ 4×，不机械套用插画算法。启动至主菜单现有 v12 资源冻结，发现对应资源即报告跳过；已有 v13/v14 高清版本需由协调者确认是否确需重做。

## 交付
保持整个图集画布和每个切片的相对坐标，缩放后的坐标=原坐标×倍率；不重排、不裁边、不加留白。不更改动作姿态、碰撞含义、角色装备轮廓、文字内容、按钮位置。地图接缝、动画连续性、调色板变体和透明边缘须检查。对贴边切片必要时独立放大后按原坐标回填；任何处理不得跨切片混色。

每任务交 submission.json、RGBA PNG、原图与结果对比图。运行项目 tools/asset-workflow.py validate 提交目录，保存终端结果。自动检查通过仍需协调者人工看图；未查看动画组合和实机效果必须写明。最终报告列出任务、算法/版本/模型/参数、倍率、校验结果、未验证事项。不要宣称完成运行时高清接入。
